ContextGraph figures

The concept comparison and the method overview, redrawn to share one visual language. Each witness role has its own colour, amber marks memory traffic, violet marks execution feedback, and the paper's range adapter field=x → field__range=R(x,x) replaces placeholder code.

Visual encoding

  • r requirement, stated from the intended source behaviour · I input, the constructed value
  • A operation, the call exercised · O observer, checks the outcome against r
  • Memory traffic: store, link, top-3 IDs, recover
  • Execution: observations and reruns after edits
  • Source-check outcome on V− / V+. It shows how a witness is accepted and is not an experimental result.

Changes from the icon version

  • Figure 1 stacks (a) over (b) with the same past repair, issue, agent and patch columns, so only the memory interface differs.
  • Row (a) shows the three witness slots as empty, so the missing information is visible in the drawing and not left to the caption.
  • Figure 2 puts memory in a strip between the two stages. Build writes down into it and Apply reads up from it, so no evidence line crosses a stage.
  • Cropped MemCo bitmaps are replaced by drawn vector icons, so the figure needs no third-party image credit.
  • Concrete code from Section 2.3 replaces the code{ return … } placeholders.
