\section{Planned experiments: which memory is effective?}
\label{sec:planned-content}
Use 24 distinct development targets from the existing dev70 partition, spanning
at least four repositories and four operation families. Select task/source
pairs from public issues and source evidence before observing the new repairs.
Use three independent repetitions per arm, with common target and source IDs.
The proposed allocation is 72 attempts per arm; repetitions remain clustered
by target in effect estimates. The examples motivating Tables~\ref{tab:memorycontent}
and~\ref{tab:composedconditions} are a development starting point for this expansion.
