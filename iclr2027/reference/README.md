# Reference papers

Collected 2026-09-24. The two author lists are based on [Yun Peng's CV](https://www.yunpeng.site/files/CV.pdf) and [Jie Xu's CV](https://jessecu2024.github.io/files/CV_JieXu.pdf); “first-author” means the author is listed first, including papers before or after the named university affiliation. Conference and journal versions of the same work count once. Files were checked for a PDF header, a readable first page, and the expected title and first author. `SHA256SUMS.txt` records file hashes.

The repository keeps this source index and `SHA256SUMS.txt`. Downloaded PDFs remain local; use the public links in the Source columns to obtain them.
