\section{Overlap audit of initial memory pools}
\label{sec:overlap-audit}
Every initial memory pool of the main comparison
(Table~\ref{tab:evaluation-settings}) was audited before evaluation so that no
evaluated task, its reference patch, or a near duplicate of that patch can be
retrieved. The audit has two steps and was applied to each of these pools in
the same way. The curated episodic pool of the retry experiment
(Section~\ref{sec:stream}) predates this audit; that experiment therefore
also reports its result with the ten near-duplicate targets removed.

\paragraph{Instance-level exclusion.}
Each source trajectory carries its task identifier, repository, and base
commit. Trajectories whose identifier matches an evaluated task are removed.
The Nebius SWE-bench-extra trajectories that seed the Verified500 pool come
from a different task collection, and none of the 500 SWE-bench Verified
evaluation instances appears among them, so the evaluated issues, their
reference patches, and their hidden tests are absent from memory. The
Related-Lite99 pool is built from trajectories on SWE-ContextBench historical
tasks and contains none of the 99 targets. The DeepSWE113 pool contains only
LoLBench repository trajectories; no DeepSWE task or repository snapshot appears
in it, and the LoLBench and DeepSWE113 repository sets are disjoint. The
LoLBench pool excludes the 20 evaluated Python tasks.

\paragraph{Patch-similarity exclusion.}
Instance identifiers do not catch the same fix recorded under a different task.
We therefore compare the reference patch of every evaluated task with every
patch in the pool using token-Jaccard similarity, the criterion that identified
ten near-duplicate sources in the curated episodic pool
(Section~\ref{sec:stream}). Pool entries with similarity of at least 0.85 to
any evaluated task's reference patch were removed before the main comparison.
Table~\ref{tab:overlap-audit} summarizes the audit for each pool: the
instance check removed nothing, and the patch-similarity check removed
between 3 and 18 entries per pool, under 1.1\% of any pool.

\paragraph{Retrieval-time check.}
The selection logs of the main comparison record the source task of every
lesson the agent selects; after the audit above, no selected lesson can
originate from an evaluated task, and Section~\ref{sec:cross-repo} uses the
same logs to report how many originate from a different repository than the
target. Official benchmark test results are never part of the agent's context
or stored memory, including between repeated attempts
(Section~\ref{sec:setup}).
