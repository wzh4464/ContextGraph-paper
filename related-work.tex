\section{Related Work}
\label{sec:related-work}

\paragraph{Abstracting experience for coding agents.}
ExpeL and ReasoningBank extract trajectory lessons
\citep{expel2024,reasoningbank2026}. SWE-Exp and ExpeRepair reuse repair
experience, and STAIR abstracts past repairs into hierarchical plans
\citep{sweexp2025,experepair2026,stair2026}. MemGovern distills human
repair histories into experience cards that code agents search and browse
\citep{memgovern2026}, and Agent KB serves planning guidance and diagnostic
feedback from a cross-framework experience base \citep{agentkb2025}.
Memory Transfer Learning finds that abstraction determines how well coding
memories transfer across domains and that transfer grows with the memory pool
\citep{transfer2026}; we observe both effects in repository-level repair
(Sections~\ref{sec:ablation} and~\ref{sec:cross-repo}).
CLIN stores causal abstractions of the form ``X may be necessary for Y''
\citep{clin2023}, AutoGuide pairs guidelines with the context in which they
apply \citep{autoguide2024}, and Agent Workflow Memory induces reusable
workflows \citep{awm2025}, all for web navigation and simulated environments.
ContextGraph brings condition-structured lessons to repository-level repair
and links lessons to their source trajectories and the errors they address.
RETester generates tests from bug reports, MIRA verifies repair memories
against evidence, and TRACE turns corrections into runtime checks
\citep{retester2025,mira2026,trace2026}; in ContextGraph, the agent applies
lessons through its own reproductions and tests.

\paragraph{Retrieving related experience.}
A-MEM links notes, Zep organizes temporal facts, and HippoRAG retrieves through
graph traversal \citep{amem2025,zep2025,hipporag2024}. ExpGraph combines
experience graphs, personalized PageRank, utility ranking, and a trained
retrieval controller \citep{expgraph2026}, and Supermemory combines relational
updates and hybrid retrieval \citep{supermemoryreport2026}. SWE-ContextBench
evaluates memory-assisted repair and finds that a supplied summary of the
related history helps more than the supplied history itself
\citep{swecontext2026}.
ContextGraph lets the agent search its graph with its full context and select
lessons; MemGovern also pairs abstracted experience with agent search, and our
ablations measure how much such a pairing matters. Table~\ref{tab:positioning}
places these methods in the design space that Section~\ref{sec:experiments}
measures.

\paragraph{Updating memory and improving agents.}
MemGPT and SWE-MeM manage memory access and coding histories
\citep{memgpt2023,swemem2026}; ACE evolves context, MemOp optimizes memory
utility, and AdaRepair-Mem selects experience by repair stage
\citep{ace2026,memop2026,adarepairmem2026}. G\"odel Agent and the Darwin
G\"odel Machine modify agent code, RRSI regularizes harness changes, and
AlphaEvolve evolves programs through executable evaluation
\citep{godelagent2025,dgm2026,rrsi2026,alphaevolve2025}. ContextGraph improves
the agent without changing its parameters or code: it adds lessons from
successes and failures after each task and makes them immediately available.
