\section{Related Work}
\label{sec:related-work}

\paragraph{Abstracting experience for coding agents.}
ExpeL and ReasoningBank extract trajectory lessons
\citep{expel2024,reasoningbank2026}. SWE-Exp and ExpeRepair reuse repair
experience; MemGovern and STAIR organize cards and plans
\citep{sweexp2025,experepair2026,memgovern2026,stair2026}.
Memory Transfer Learning finds that abstract insights transfer across coding
domains more readily than detailed traces \citep{transfer2026}.
Detailed traces can instead carry misleading implementation assumptions. ContextGraph
retains strategies and warnings with their applicability context and outcomes.
RETester generates tests from bug reports, MIRA retains requirements, and
TRACE turns corrections into runtime checks
\citep{retester2025,mira2026,trace2026}; ContextGraph returns textual
guidance and leaves verification to the agent's own tests.

\paragraph{Retrieving related experience.}
A-MEM links notes, Zep organizes temporal facts, and HippoRAG retrieves through
graph traversal \citep{amem2025,zep2025,hipporag2024}.
ExpGraph combines experience graphs, personalized PageRank, utility ranking,
and a trained retrieval controller
\citep{expgraph2026}. ContextGraph connects repair strategies to recurring
errors, shared rules, and source trajectories. The agent uses its full context
to search these records and select useful guidance. Supermemory combines relational updates and
hybrid retrieval \citep{supermemoryreport2026}; SWE-ContextBench evaluates
memory-assisted repair \citep{swecontext2026}.

\paragraph{Updating memory and improving agents.}
MemGPT and SWE-MeM manage memory access and coding histories
\citep{memgpt2023,swemem2026}. ACE evolves context, MemOp optimizes memory
utility, and AdaRepair-Mem selects experience by repair stage
\citep{ace2026,memop2026,adarepairmem2026}.
G\"odel Agent and the Darwin G\"odel Machine modify agent code; RRSI
regularizes harness changes \citep{godelagent2025,dgm2026,rrsi2026}.
AlphaEvolve evolves programs through executable evaluation; MulVul evolves
prompts across generator and executor models \citep{alphaevolve2025,mulvul2026}.
ContextGraph adds lessons from successes and failures after each task and
makes them immediately available for retrieval.
Subsequent tasks retrieve this growing experience before planning and after
errors, without updating model parameters.
