\section{Extension: full-context code-agent retrieval}
\label{sec:agentic-retrieval}
This proposed extension lets a selector explore the experience graph using
the coding agent's complete current-task context. Beyond the issue, that
context includes inspected code, earlier actions, and observed failures,
which can change the guidance needed for the next decision.

Let $C_t$ contain the task and conversation, inspected code, edits, actions,
and observations available at step $t$. The selector operates on $C_t$ and
a frozen experience pool $\mathcal{M}$. It can issue semantic or keyword
queries, open source records, follow links between strategies and errors,
and compare lessons from different experiences. It returns strategies and
warnings together with their source IDs and an explanation of how they can
help the current repair. Search can recur before a new plan or after an error.

Full context describes access to the current task; the selector explores
the experience pool through search and record reading. The returned advice
uses the same memory interface as Section~\ref{sec:method}, and the coding
agent applies it through its own investigation, edits, and tests.

\paragraph{Prototype implementation.}
The repository provides context-aware candidate reranking and a selector
over all 300 compact experience cards. These prototypes cap task or
working-state text at 4,000 characters and limit candidate content. They
provide starting points for the proposed full-context, iterative search.
